# M4 非研发可用性任务卡（需真人执行）

> 目的：验证「业务/运营同学能不能不靠研发，就完成一次业务规则变更」。
> 这是 A/B 实验四个指标里唯一需要真人的一项。请把本卡交给一位**非研发**同事，
> 各按两组各跑一遍，记录用时与卡点，结果回填 §M4 记录表。

## 任务（对两组各执行一次）

把「免费等候时间」从 30 分钟改成 20 分钟，然后回答：这单的等候费应计变成了多少？

### B 组（本体）：预期操作路径

1. 打开本体声明文件（`semantic_layer.json`），找到 `pricing.waiting.free_minutes`；
2. 把 `30` 改成 `20`，保存；
3. 重新运行诊断（或调用 `fee-analysis`），读出应计值；
4. 记录：耗时 / 是否需要研发介入 / 有没有提示告诉你改错了地方。

### A 组（属性图）：预期操作路径

1. 找到参数所在的服务代码或配置（`group_a/rules.yaml`）；
2. 改参数；
3. **重启服务**（改代码/配置需要重启生效）；
4. 重新算应计；
5. 记录：耗时 / 是否需要研发介入 / 还有没有第二处副本需要同步。
