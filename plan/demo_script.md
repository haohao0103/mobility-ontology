> 目标：**让领导在 20 分钟内看懂「本体系统有哪些东西」+「交互式提问能否展示价值」**
> 页面实现：`web/order-ontology.html` 的 **8 幕讲解模式**（`DEMO_STORY`，已实现 + 有浏览器彩排）
> 环境：本地部署（STG `stg-121` 不可达）。端口以实际启动为准，示例用 8799
> 页面：`http://127.0.0.1:8799/profile/order-ontology`
> 必跑自检：`DEMO_BASE=http://127.0.0.1:8799 python scripts/demo_gate.py`（全绿再上台）
> 浏览器彩排：`python scripts/browser_rehearsal.py`（真实点击 8 幕，每幕首步断言）

## 0. 开场 30 秒

> 「这系统的核心不是一张表，是一个**本体**：我们把『运单、费用项、定价规则、报价单、结算单』
> 这些业务概念，连同它们的**关系、规矩、状态流转、能做的动作、谁有权限看**一起定义在一处。
> 接下来我会带大家看八件事——每件都是**改一行本体、行为就变**的那种事实。
> 最后我会做一件事：**把同一份数据直接丢给大模型**，看看它和我们差在哪。」

不要说"这是一个图数据库"（会被理解成可视化工具），要说**"这是一套让机器理解并执行业务规则的本体"**。

## 1. 八幕主线（页面已实现，每幕配我的话术）

| 幕 | 页面标题 | 指给领导看 | 一句话价值 |
|---|---|---|---|
| **1 承重** | 本体不是说明文档，是业务行为的唯一真源 | 第 2 步 **本体版本 diff（免费等候 30→20）**；第 3 步**切版本后同一笔费用的结论翻转**，甚至标了 BLOCKER | **"离开本体做不到"的最强证据**：改的是本体 JSON，代码零改动，行为翻转 |
| **2 血缘** | 本体知道自己被谁用 | 属性级血缘（上游数据源 → 下游规则/动作）→ 对象级血缘 → 影响面 | 4097 节点 / 4129 条边的图，**不是手工维护的文档，是本体自己算出来的** |
| **3 治理** | 本体也有 Git | 不可变版本快照 + checksum；变更集 DRAFT/APPLIED；破坏性变更必须签字（承重 L13）；分支恢复 | 企业敢用的前提：**改得动，也管得住** |
| **4 语义查询** | 查的是业务语义，不是数据库表名 | Object Set 的 `from` 是本体类 `FeeItem`、`where` 是本体属性；Ontology SQL 编译到同一棵查询树；派生类型是本体声明的新视角；OSDK 生成类型化客户端 | 查询写的是**业务语言**，不是表名字段名 |
| **5 类型即契约** | 类型不是注释，是写入时必须通过的闸 | 属性类型/单位/标记；承重 L3~L8 的写入拒绝与签名校验；L11/L12 的 marking 翻转；匿名视角的真实脱敏 | 约定**在写入那一刻**就生效，不是上线前靠人核对 |
| **6 推理链** | 大模型被本体牵着走，不是自由发挥 | 工具白名单由本体裁剪；圈定类型只能从本体目录选；参与者里有 TBox 引擎；结论绑定本体版本与证据 checksum。**抽掉 `semantic_layer.json`，整条链构造即失败** | 模型负责理解人话，**本体负责决定能看什么、能算什么** |
| **7 权限** | 权限跟着本体属性走，一路传到 AI 输出 | 匿名可见 6/7 行、争议处理角色 7/7；列级 marking 脱敏；强调**数据源→类→对象→列→Agent 输出**四级传播 | 权限不是页面上的开关，是**跟着数据流走**的 |
| **8 收束** | 所有能力收束到一个可解释的结论 | 费用 25 vs **规则应计 12** + 证据 checksum + 结论绑定本体版本 | 前面七幕**汇合到一个能复核的结论**上 |

## 2. ★ 补刀：把大模型放在同一份数据上对一次

> 这一步不是锦上添花——**没有它，前七幕的价值仍停留在"我们做得更全"；
> 有了它，才是"离开本体根本算不出来"**。

```bash
python scripts/demo_coverage_audit.py     # 内含「裸 SQL 对照」与「裸 LLM 对照」
```

**现场话术与实测原文（2026-11-21，可直接引用）**：

| | 裸大模型（给原始数据，不给本体） | 本体（`function.fee_breakdown`，0.01 秒） |
|---|---|---|
| 等候费按规则**应收**多少 | **0.00 元**（把 `quoted_amount=0` 当成应计值） | **12.00 元**（`ceil(max(0, 53-30)/5)*2.4`，版本 2026.10，生效期 10-01~12-31，车型费率） |
| 差额判断 | 多收 25 元，「**目前凭不上**」 | 应计 12 / 实收 25 / **超收 13 元**，附证据链 |
| 依据 | 无 | 规则 ID + 版本 + 生效期 + 证据 ID + checksum |

> 「**差的 13 元不在数据里**——它在计价规则里：公式、版本、生效期、车型费率。
> 这就是本体系统的价值：**把规则变成机器可执行、可审计的东西**，而不是每次靠人记住、或者靠模型猜。」

**为什么这个问题有效、原来那个无效**（2026-11-21 实证审计）：
原来的问法「这单为什么多 38 元」「高速费谁认领」「凭证是哪条」——**裸大模型能答到七八成**
（它自己就给出了「等候费 25 + 高速费 13」的勾稽表，也答出了「ETC / fee:F004 / 凭证无法确定」）。
**演示若用这种问题，领导自己一试就会发现"它也答得不错"，本体价值被稀释。**
所以问题要问成**数据里没有答案的那种**：应计值、状态机前置、缺口语义。

## 3. 三个问不出来的东西（用操作演示，不用提问）

审计实测：交互式问题能串起 **8~11 个类、160~199 个本体项、14/16 条规则、7/7 种费用类型**，
但**标记/强制访问控制、接口多态、变更治理**这三个 Palantir 最具特色的要素，**提问问不出来**
（它们不是"业务知识问题"，而是"行可见性 / 运行时路由 / 变更纪律"）。
→ 8 幕已经用**操作**覆盖了它们：**ACT 5（marking 翻转 + 匿名脱敏）**、
**ACT 3（签字与回滚）**、**ACT 7（四级传播）**。

> 讲解口径：**「交互演示展示本体怎么推理，操作演示展示本体怎么被约束——后者才是企业愿意付钱的理由」**。

## 4. 领导可能问的（诚实口径）

| 问题 | 怎么答 |
|---|---|
| 「跟直接问大模型有什么区别？」 | **当场给实测**（§2）：裸大模型说"应收 0、多收 25、凭不上"；本体说"按 R-WAIT-01 应计 12、超收 13"，带公式、版本、生效期与证据链。另外：本体路径 **0.01 秒且结果可复现**，模型每次可能不同；**本体规则改动会被门禁拦住并要求签字** |
| 「这跟普通数据库 / BI 报表的区别？」 | 数据回答"是什么"，本体回答"**该怎么做、不能做什么、凭什么这么算**"。"装货完成后还能改派司机吗"——普通表查不出来，状态机一句话给答案 |
| 「数据量多大？接真实业务了吗？」 | **诚实**：本体声明 500 类、503 链接、1961 属性、16 规则、15 动作、8 状态机；**当前有真实对象的是主链路 18 类（深水区 100%，全量 3.6%）**。数据是**剧本数据**（含人为构造的异常场景，用于验证检测能力）；下一步就是按 `data_sources` 契约接真实系统 |
| 「这不就是给表加了注释吗？」 | 反例：注释写"等候费 12 元"，本体里有**公式**（等待 53 分 − 免费 30 分，向上取整 5 分钟块，2.4 元/块）**和版本与生效期**。改报价规则时差额归因**跟着变**，注释不会 |
| 「大模型答错了怎么办？」 | 三层：① 算钱不交给模型（规则在本体）；② 每个结论带规则/证据/来源/本体版本，可复核；③ 口径不一致会**报口径冲突**，不静默取一个；④ 抽掉本体，推理链**构造即失败** |
| 「能自动执行动作吗？会不会误操作？」 | 现在**只提案不执行**：动作先做前置校验（状态/角色/规则），人工确认才写；写回有审计与幂等键。自动执行是我们明确**暂缓**的部分 |
| 「这套能带来什么？」 | 落点建议：**新业务上线不用再口头对齐规则**——规则、状态、动作、权限写在一处，Agent 与人用同一套；改一处所有入口同步生效，且改动要过门禁签字 |

## 5. 风险与兜底

| 风险 | 征兆 | 兜底 |
|---|---|---|
| **LLM 不通 / 503** | 推理链报错或卡住 | 系统已内建三层保险：① 指数退避重试（429/5xx/网络抖动/空响应；401/403 不重试）；② 模型输出格式不规范时宽松收下；③ 工具预算用尽或模型彻底失败时**降级成"初步结论"而不是 503**。即便如此仍失败，就**切确定性路径**：`function.fee_breakdown` / 状态机 / 动作预检全是 0.01~0.1 秒级、**完全不依赖大模型**——顺势讲"**这就是本体的价值：结论不依赖外部模型**" |
| **页面打不开 / 渲染异常** | 白屏 | 切 REST：`/docs`（Swagger）、`/freight/ontology`、`/freight/ontology/state-machines` 都能看 |
| **等待焦虑（45~90 秒）** | 领导盯着空白 | 先讲完 ACT 1~5（都是秒级操作），再进 ACT 6；进推理链前先说"它要自己查一轮，大概一分钟" |
| **对照实验超时** | 裸 LLM 慢 | 对照实验**提前跑一次**（`scripts/demo_coverage_audit.py`），把结果贴在旁边；现场只展示结论 |
| **端口被占 / 服务没起** | demo_gate 报 FAIL | `lsof -nP -tiTCP:8799 -sTCP:LISTEN \| xargs kill` 后重启；**上台前 5 分钟不要重启服务** |
